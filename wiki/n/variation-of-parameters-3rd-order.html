Variation of Parameters - 3rd Order

Related: Variation of Parameters · Undetermined Coefficients - Higher Order · Higher Order Homogeneous ODEs

Setup

Consider the third order linear non-homogeneous ODE (standard form)

y′′′+p(x)y′′+q(x)y′+r(x)y=f(x).

Assume yc​=C1​y1​+C2​y2​+C3​y3​ is known, with y1​,y2​,y3​ linearly independent solutions of the homogeneous equation (W(y1​,y2​,y3​)=0). Seek

yp​=u1​(x)y1​+u2​(x)y2​+u3​(x)y3​.

Imposing the Auxiliary Conditions

Differentiate yp​ once: yp′​=(u1′​y1​+u2′​y2​+u3′​y3​)+(u1​y1′​+u2​y2′​+u3​y3′​).

Condition 1: u1′​y1​+u2′​y2​+u3′​y3​=0, leaving yp′​=u1​y1′​+u2​y2′​+u3​y3′​.

Differentiate again: yp′′​=(u1′​y1′​+u2′​y2′​+u3′​y3′​)+(u1​y1′′​+u2​y2′′​+u3​y3′′​).

Condition 2: u1′​y1′​+u2′​y2′​+u3′​y3′​=0, leaving yp′′​=u1​y1′′​+u2​y2′′​+u3​y3′′​.

Differentiating once more and substituting yp​,yp′​,yp′′​,yp′′′​ into the ODE, the homogeneous parts cancel (each yi​ solves L[yi​]=0), leaving exactly

u1′​y1′′​+u2′​y2′′​+u3′​y3′′​=f(x).

The Linear System

u1′​y1​+u2′​y2​+u3′​y3​u1′​y1′​+u2′​y2′​+u3′​y3′​u1′​y1′′​+u2′​y2′′​+u3′​y3′′​​=0=0=f(x)​

The coefficient matrix is exactly the Wronskian matrix of y1​,y2​,y3​; since W=0 this system has a unique solution.

Solving by Cramer's Rule

Let W=W(y1​,y2​,y3​). Let W1​,W2​,W3​ be W with the 1st/2nd/3rd column replaced by (0,0,f(x))T. Then

u1′​=WW1​​,u2′​=WW2​​,u3′​=WW3​​

(each Wi​ computed by expanding along the replaced column, since only the last entry is nonzero). Integrate (drop constants) to get u1​,u2​,u3​, then

yp​=u1​y1​+u2​y2​+u3​y3​,y=yc​+yp​.
