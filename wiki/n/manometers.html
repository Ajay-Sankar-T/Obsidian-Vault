The one rule that solves every manometer problem

Starting from a known-pressure point, walk through the connected fluid column toward the unknown point:

Moving DOWN→+ρgh​Moving UP→−ρgh​

Same level, same continuous fluid→P1​=P2​​

This is nothing more than repeated application of P2​=P1​+ρgh from Pressure and the Hydrostatic Equation, plus the "pressure depends only on depth" fact from Static Equilibrium that licenses equating pressures at the same horizontal level within one connected fluid.

Piezometer

The simplest manometer — a vertical open tube connected directly to the pressure point:

P=ρgh​

(gauge pressure, h = height the fluid rises in the tube). Only works for moderate positive gauge pressures in liquids (a large P would need an impractically tall tube; a negative gauge pressure can't be read at all since the tube would need to "suck" fluid up from nothing).

General procedure

  1. Identify the known-pressure reference point (often atmospheric, P=0 gauge).
  2. Trace a path through the connected fluid(s) to the unknown point, applying +ρgh for every downward step and −ρgh for every upward step, using the density of whichever fluid occupies that segment (multi-fluid manometers require tracking density changes at each interface).
  3. Set the total equal to the unknown pressure.
