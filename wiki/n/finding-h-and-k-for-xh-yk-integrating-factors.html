Finding h and k for x^h y^k Integrating Factors

Related: Integrating Factors

Problem

Suppose xhyk is an IF for the DE

xayb(mydx+nxdy)+xcyd(pydx+qxdy)=0(5)

Find h and k if np=mq.

Solution

Multiplying xhyk with the given DE:

(xa+hyb+kmy+xc+hyd+kpy)dx+(xa+hyb+knx+xc+hyd+kqx)dy=0

which must be exact. Here M=mxa+hyb+k+1+pxc+hyd+k+1 and N=nxa+h+1yb+k+qxc+h+1yd+k.

Using My​=Nx​:

mxa+h(b+k+1)yb+k+pxc+h(d+k+1)yd+k=n(a+h+1)xa+hyb+k+q(c+h+1)xc+hyd+k

Equating coefficients:

m(b+k+1)=n(a+h+1)

p(d+k+1)=q(c+h+1)

which rearranges to the linear system

nh−mk=m(b+1)−n(a+1)

qh−pk=p(d+1)−q(c+1)(A)

Since Δ=mq−np=0, this system has a unique solution

h=ΔΔ1​​,k=ΔΔ2​​

(by Cramer's rule, with Δ1​,Δ2​ the determinants formed by replacing the respective column of Δ with the RHS of (A)).

Worked Example

Solve (x1/2y−xy2)dx+(x3/2+x2y)dy=0.

Write the equation as

x1/2(ydx+xdy)+xy(−ydx+xdy)=0.

Comparing with (5): a=21​,b=0,c=1,d=1,m=1,n=1,p=−1,q=1.

Then (A) reduces to

h−k=−21​,h+k=−4

giving h=−49​, k=−47​.

So the IF is x−9/4y−7/4.

General solution: −34​x−3/4y−3/4+4x−1/4y1/4=K.
