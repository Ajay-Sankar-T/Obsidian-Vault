Integrating Factors

Related: Exact Differential Equations, Linear Differential Equations

▶ Many first-order equations Mdx+Ndy=0 are not exact as they stand (My​=Nx​).

▶ Often, however, multiplying the entire equation by a suitably chosen function μ(x,y) makes it exact. Such a function is called an integrating factor (IF).

A function μ(x,y)=0 is called an integrating factor for Mdx+Ndy=0 if the equation μMdx+μNdy=0 is exact.

In this case, ∂y∂​(μM)=∂x∂​(μN). Expanding this condition gives the integrating factor PDE:

μy​M−μx​N=μ(Nx​−My​).(1)

In general (1) is a PDE for μ, harder to solve than the original ODE. However, in many practical cases μ can be assumed to depend on only one variable (x alone, y alone, or a simple combination such as xy or x+y), which reduces the PDE to an ordinary differential equation for μ.

Case 1: μ is a function of x alone

Here μy​=0. From (1):

μ1​dxdμ​=NMy​−Nx​​

Since the LHS depends only on x, we need NMy​−Nx​​:=f(x) to be a function of x only. Integrating,

μ(x)=exp(∫f(x)dx)=exp(∫NMy​−Nx​​dx).

Case 2: μ is a function of y alone

Here μx​=0. From (1):

μ1​dydμ​=−MMy​−Nx​​

We need −MMy​−Nx​​:=g(y) to be a function of y only.

μ(y)=exp(∫g(y)dy)=exp(∫MNx​−My​​dy).

Case 3: μ is a function of the product xy

With μ=μ(z), z=xy:

μ1​dzdμ​=yN−xMMy​−Nx​​

We need yN−xMMy​−Nx​​:=h(z) to be a function of z only.

μ(z)=exp(∫h(z)dz)=exp(∫yN−xMMy​−Nx​​dz),z=xy.

Worked Example — Case 2
