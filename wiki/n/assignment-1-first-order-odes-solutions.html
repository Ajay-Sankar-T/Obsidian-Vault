0. Theory toolkit

0.1 Direction fields and isoclines

For y′=f(x,y) the slope at (x,y) is f(x,y). The isocline of slope m is the curve f(x,y)=m; along it every solution crosses with the same slope (Isoclines).

0.2 Exact equations

Mdx+Ndy=0 is exact iff My​=Nx​ (on a simply connected domain). Then there is a potential F with Fx​=M, Fy​=N and the solutions are F(x,y)=C.

F=∫Mdx+g(y),g′(y)=N−∂y​∫Mdx

0.4 Linear and Bernoulli equations

  • Linear: y′+P(x)y=Q(x), IF =e∫P,  ye∫P=∫Qe∫Pdx+C.
  • Bernoulli: y′+Py=Qyn (n=0,1): substitute v=y1−n, which gives the linear equation v′+(1−n)Pv=(1−n)Q.
  • If the equation is linear in x as a function of y (dx/dy+P(y)x=Q(y)), swap the roles of the variables.

0.6 Which method?

flowchart TD
    S["M dx + N dy = 0 or y' = f"] --> L{"linear in y or in x?"}
    L -- "yes" --> LIN["integrating factor e^(int P)"]
    L -- "no" --> B{"Bernoulli y^n on the right?"}
    B -- "yes" --> BER["v = y^(1-n), then linear"]
    B -- "no" --> E{"M_y = N_x ?"}
    E -- "yes" --> EX["exact: F = int M dx + g(y)"]
    E -- "no" --> IF{"IF of x, y, xy, x+y^2 ...?"}
    IF -- "yes" --> MU["multiply by mu, then exact"]
    IF -- "no" --> H{"homogeneous or recognisable dF?"}
    H -- "yes" --> SUB["v = y/x or group terms"]

Q3 – Integrating factor of a sum

When does Mdx+Ndy=0 have an integrating factor that is a function of (i) z=x−y, (ii) z=x2−3y?
Show solution

Put μ=μ(z) in (μM)y​=(μN)x​:

μ′(z)(zy​M−zx​N)=μ(Nx​−My​) ⟹ μμ′​=zx​N−zy​MMy​−Nx​​.

An IF of the form μ(z) exists iff the right side is a function of z alone; then μ=exp∫φ(z)dz.

(i) z=x−y: zx​=1, zy​=−1, so zx​N−zy​M=M+N.

M+NMy​−Nx​​ is a function of (x−y) only​,μ=exp∫M+NMy​−Nx​​dz.

(ii) z=x2−3y: zx​=2x, zy​=−3, so zx​N−zy​M=2xN+3M.

2xN+3MMy​−Nx​​ is a function of (x2−3y) only​,μ=exp∫2xN+3MMy​−Nx​​dz.

Examples (checked): (i) ex−ydx+ex−ydy=0 gives ratio −1, so μ=e−z and the equation becomes dx+dy=0. (ii) e−(x2−3y)dx=0 gives ratio 1, so μ=ez.
