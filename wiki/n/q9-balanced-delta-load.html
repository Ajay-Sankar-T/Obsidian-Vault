EE1100 Tutorial 4 — Q9: Balanced Delta Load

A 220V (L-L) three-phase balanced voltage is applied to a balanced delta-connected load. Phase current Iab​=10∠−30∘A.

1. Theory

  • Delta Connection: Line voltage equals phase voltage (VL​=Vph​). Line current is 3​ times phase current (IL​=3​Iph​).
  • Total Power: Ptotal​=3Vph​Iph​cosϕ=3​VL​IL​cosϕ.
  • Impedance: Z=Iph​Vph​​.

2. Solution

(a) Phase and Line Currents Phase currents: Iab​=10∠−30∘A Ibc​=10∠(−30∘−120∘)=10∠−150∘A Ica​=10∠(−30∘+120∘)=10∠90∘A

Line currents: IL​=3​Iph​=3​×10=17.32A. Phase of Ia​=Phase of Iab​−30∘=−60∘. Ia​=17.32∠−60∘A Ib​=17.32∠−180∘A Ic​=17.32∠60∘A

(b) Total Power Vph​=220V. Iph​=10A. ϕ=−30∘ (Current lags voltage Vab​∠0∘). Ptotal​=3×220×10×cos(30∘)=6600×0.866=5715.6W​. Qtotal​=3×220×10×sin(30∘)=6600×0.5=3300Var​ (lag). (Note: Prompt answer says 2857.8 Var, check calculation: 3×220×10×sin(30∘) is 3300. If VL​ was different or pf changed, it would vary. Using Vph​=220,Iph​=10,ϕ=30∘→3300).

(c) Resistive Portion of Impedance Z=Iph​Vph​​=10220​=22Ω. R=Zcosϕ=22cos(30∘)=22×0.866=19.05Ω​.
