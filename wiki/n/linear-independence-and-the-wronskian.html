Linear Independence and the Wronskian

Related: Solution of a Second Order ODE

Initial Value Problem (IVP)

Consider a 2nd order linear homogeneous DE:

y′′+P(x)y′+Q(x)y=0,x∈I(3)

with initial conditions y(x0​)=y0​, y′(x0​)=y0′​, x0​∈I (4).

Since (3) is 2nd order linear, its general solution has two arbitrary constants: y=C1​y1​+C2​y2​, where y1​,y2​ are suitable solutions of (3). Using (4), we solve for C1​,C2​ to get the unique particular solution of the IVP — the curve through (x0​,y0​) with slope y0′​ there.

Linear Independence

Two functions y1​,y2​ on I are linearly independent if c1​y1​(x)+c2​y2​(x)=0 ∀x∈I⇒c1​=c2​=0. Otherwise they are linearly dependent.

Equivalently, y1​,y2​ are dependent iff one is a constant multiple of the other.

  • ex,e2x are linearly independent on any interval.
  • sinx,2sinx are linearly dependent.

Linear independence of solutions is key to forming the general solution.

The Wronskian

Definition. For y1​(x),y2​(x) differentiable on I,

W(y1​,y2​)(x)=​y1​y1′​​y2​y2′​​​=y1​y2′​−y2​y1′​.

  • W is itself a function of x on I; it provides a computable test for linear independence.
  • If W(y1​,y2​)(x0​)=0 for some x0​∈I, then y1​,y2​ are linearly independent on I.
  • If y1​,y2​ are linearly dependent, then W(y1​,y2​)(x)≡0 on I.
  • Note: W≡0 does not always imply dependence for arbitrary functions (only for solutions of a common linear ODE — see Abel's Formula).

Wronskian Test for Solutions

Theorem. Let y1​,y2​ be solutions of y′′+P(x)y′+Q(x)y=0 on I. Then y1​,y2​ are linearly independent on I iff W(y1​,y2​)(x)=0 for every x∈I.

Proof (⇒)

Suppose y1​,y2​ are linearly independent on I. Let W(x)=y1​y2′​−y2​y1′​. Differentiating:

W′(x)=y1′​y2′​+y1​y2′′​−y2′​y1′​−y2​y1′′​=y1​y2′′​−y2​y1′′​.

Since both satisfy y′′=−P(x)y′−Q(x)y:

W′=y1​(−Py2′​−Qy2​)−y2​(−Py1′​−Qy1​)=−P(y1​y2′​−y2​y1′​)=−PW.

Hence W′+PW=0 (Abel's Formula), giving W(x)=Ce−∫P(x)dx.

Suppose, contrary to the claim, W(x0​)=0 for some x0​. Then C=0 (since e−∫Pdx=0), so W(x)≡0 on I. On any interval where y1​=0:

(y1​y2​​)′=y12​y1​y2′​−y2​y1′​​=y12​W(x)​=0.

So y2​/y1​=k constant, i.e. y2​=ky1​ — contradicting independence. Thus W(x)=0 for every x∈I.

Proof (⇐)

Suppose W(x)=0 for every x∈I. Assume, to the contrary, y1​,y2​ are linearly dependent: c1​y1​+c2​y2​=0 non-trivially. WLOG c2​=0, so y2​=−c2​c1​​y1​, y2′​=−c2​c1​​y1′​. Then

W(y1​,y2​)=y1​(−c2​c1​​y1′​)−(−c2​c1​​y1​)y1′​=0,

contradicting W=0. Hence y1​,y2​ are linearly independent. ■
