T8-Q10: A 50 hp Motor from the Approximate Equivalent Circuit

EE1100tutorial-solutionmachinesinduction-machineequivalent-circuit

Hub: Tutorial 8 - Induction Machines · Theory: Theory - Three-Phase Induction Machines · Previous: T8-Q9 - Power Flow and Efficiency of a Delta-Connected Motor · Next: T8-Q11 - Equivalent Circuit and Starting of an Induction Motor

A three-phase, four-pole, 50 hp, 440 V, 60 Hz, Y-connected induction motor has, per phase, r1​=0.10, x1​=0.35, r2′​=0.12, x2′​=0.40 Ω. Stator core losses are 1200 W and rotational losses 950 W; at no load the motor draws 18 A at power factor 0.089 lagging. At a slip of 2.5 % find (a) the input line current and power factor, (b) the developed torque, (c) the output horsepower, (d) the efficiency. [Sheet: 58.2 A, 0.895 lag; 201 N·m; 48.25 hp; 89.6 %]

Tests: the approximate equivalent circuit (shunt branch at the input), complex-current addition, power flow.

Given

Per phase: V1​=440/3​=254.0 V. ns​=120×60/4=1800 rpm, ωs​=188.5 rad/s. s=0.025.

Principle and why it applies

Because the magnetising branch is small compared with the series impedance, it can be moved to the input terminals: the stator current is then the phasor sum of the load (rotor) current and the no-load current I0​ given by the no-load test:

Iˉ1​=Iˉ2′​+Iˉ0​,Iˉ2′​=(r1​+r2′​/s)+j(x1​+x2′​)Vˉ1​​.

Solution

Load branch: r2′​/s=0.12/0.025=4.8 Ω, so Z=(0.10+4.8)+j(0.35+0.40)=4.9+j0.75=4.957∠8.70∘ Ω:

Iˉ2′​=4.957∠8.70∘254.0​=51.25∠−8.70∘ A.

No-load current: Iˉ0​=18∠−cos−10.089=18∠−84.9∘=1.60−j17.93 A.

(a) Iˉ1​=(50.66−j7.75)+(1.60−j17.93)=52.26−j25.68=58.2∠−26.2∘ A, so the power factor is cos26.2∘=0.897 lagging.

(b) Developed torque. Air-gap power per phase is I2′2​r2′​/s, so

Pg​=3×51.252×4.8=37818 W,Tdev​=ωs​Pg​​=188.537818​=200.6 N⋅m.

(c) Output power:

Pmech​=(1−s)Pg​=0.975×37818=36872 W,Pout​=Pmech​−Prot​=36872−950=35922 W=74635922​=48.15 hp.

(d) Efficiency. Input power from the circuit: Pin​=3​VL​I1​cosϕ=3×254.0×58.2×0.897=39830 W, so

η=3983035922​=90.2 %.

If instead the losses are summed with the stator copper loss taken on the full line current (as the sheet appears to do): Pcu1​=3×58.22×0.10=1017 W, Pcu2​=sPg​=945 W, core 1200 W, rotational 950 W; η=35922+411235922​=89.7 %.

Result

I1​=58.2 A, pf=0.897 lag;  Tdev​=200.6 N⋅m;  Pout​=35.9 kW=48.15 hp;  η≈90 % (90.2 or 89.7 % depending on the loss bookkeeping)​

Check

No-load power from the data: P0​=3​×440×18×0.089=1221 W ≈ the stated core loss (1200 W): the shunt branch represents the core loss, so the rotational loss 950 W is a separate mechanical loss subtracted after Pmech​ ✓. The torque 201 N·m agrees with the sheet; the output 48.15 hp differs from the printed 48.25 by 0.2 % (the sheet's 746 W/hp and rounding).

Trap / alternative

  • The efficiency differs by 0.5 % according to whether I02​r1​ is counted; the approximate circuit ignores the magnetising current in r1​, so 90.2 % is the consistent value within that circuit, while 89.7 % (and the sheet's 89.6 %) uses the full I1​ in r1​.
  • I1​ is the phasor sum, not 51.25+18=69.3 A.
  • Use ωs​ (synchronous), not the rotor speed, for the developed torque.
