General Solution Structure Theorem

Related: Existence, Uniqueness, and Fundamental Sets · Reduction of Order

Theorem. If {y1​,y2​} is a fundamental set of solutions of L[y]=0 on I, then every solution y of L[y]=0 on I can be written as

y(x)=c1​y1​(x)+c2​y2​(x)

for unique constants c1​,c2​.

This expression is the general solution (or complementary function) yc​ — it represents all solutions of the homogeneous DE.

A particular solution yp​ of L[y]=R(x) is any single function satisfying it (no arbitrary constants).

Structure Theorem. If yp​ is a particular solution of L[y]=R(x), and yc​=c1​y1​+c2​y2​ is the general solution of the associated homogeneous equation L[y]=0, then the general solution of L[y]=R(x) is

y(x)=yc​(x)+yp​(x)=c1​y1​(x)+c2​y2​(x)+yp​(x).

Proof Sketch

If y is any solution of L[y]=R(x), define u=y−yp​. Since L[yp​]=R(x):

L[u]=L[y]−L[yp​]=R(x)−R(x)=0.

So u solves the homogeneous equation, hence u=c1​y1​+c2​y2​. Therefore y=yp​+c1​y1​+c2​y2​, proving every solution has this form.

Conversely, L[yp​+c1​y1​+c2​y2​]=R(x)+0+0=R(x), so it is indeed a solution.

This decomposition (yc​+yp​) is fundamental to solving non-homogeneous equations — see Undetermined Coefficients and Variation of Parameters for methods to find yp​.

Summary of Key Theorems

  • Existence-Uniqueness: IVP has a unique solution on all of I when P,Q,R continuous.
  • Superposition: linear combinations of homogeneous solutions are solutions.
  • Solution space S of L[y]=0 is a 2-dimensional vector space.
  • Wronskian test + Abel's formula: determine independence via a single point check.
  • General solution of L[y]=0: yc​=c1​y1​+c2​y2​ (fundamental set).
  • General solution of L[y]=R(x): y=yc​+yp​.
