EE1100 Tutorial 4 — Q12: Star Load Voltage and Current

A balanced three-phase star-connected load has impedance Z=46∠0∘Ω. Voltage Van​=20∠30∘V.

1. Theory

  • Star Connection: Iph​=ZVph​​.
  • Symmetry: Vbn​ and Vcn​ are shifted by −120∘ and +120∘ from Van​.
  • Line Voltage: Vac​=Van​−Vcn​.

2. Solution

(a) Currents in phases a, b, c Ia​=46∠0∘20∠30∘​≈0.435∠30∘A​ (Note: Prompt ans says 5∠−30∘, likely due to different V or Z values in their version). Wait, prompt ans says: 5∠−30∘,5∠−150∘,5∠90∘. If I=5A and Z=46Ω, then Vph​=5×46=230V. The prompt text says Van​=20∠30∘V, but the answer says I=5A. There is a contradiction in the prompt's provided values vs answers. I will provide the solution based on the provided text values.

Using text: Van​=20∠30∘V,Z=46Ω. Ia​=4620∠30∘​=0.435∠30∘A. Ib​=0.435∠(30∘−120∘)=0.435∠−90∘A. Ic​=0.435∠(30∘+120∘)=0.435∠150∘A.

(b) Voltage from line b to neutral n Vbn​=20∠(30∘−120∘)=20∠−90∘V​.

(c) Voltage from line a to line c (Vac​) Vac​=Van​−Vcn​. Vcn​=20∠(30∘+120∘)=20∠150∘V. Vac​=20∠30∘−20∠150∘. Using phasors: (20cos30+j20sin30)−(20cos150+j20sin150) =(17.32+j10)−(−17.32+j10)=34.64+j0=34.64∠0∘V​.
