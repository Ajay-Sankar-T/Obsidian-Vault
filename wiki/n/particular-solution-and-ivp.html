Particular Solution and IVP

Related: First Order ODEs

▶ A particular solution is obtained by assigning a specific value to the arbitrary constant.

▶ For dxdy​=2x, y(1)=5, the particular solution is obtained from the general solution y=x2+C using the given condition.

▶ Here 5=1+C⟹C=4 gives the particular solution as y=x2+4.

Initial Value Problem (IVP)

A first-order differential equation together with an initial condition y(x0​)=y0​ is called an initial value problem (IVP).

dxdy​=f(x,y),y(x0​)=y0​.

Geometric Interpretation

  • The general solution represents a family of curves.
  • The initial condition selects the unique curve passing through the specified point.
  • Thus, solving an IVP means finding the integral curve satisfying y(x0​)=y0​.

See also: Isoclines for a graphical way to visualize solution curves, and Existence and Uniqueness (Picard-Lindelof Theorem) for when an IVP is guaranteed to have a unique solution.
