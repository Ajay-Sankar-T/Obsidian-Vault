Cauchy Problem for First Order PDEs

What it is

The Cauchy problem asks for the integral surface of ap+bq=c that contains a given space curve

Γ: x=x0​(s), y=y0​(s), u=u0​(s)

(equivalently, u is prescribed on a curve in the xy-plane). The general solution G(φ,ψ)=0 has one arbitrary function; the data fix it.

Method

  1. Find the two first integrals φ=c1​, ψ=c2​ (Lagrange's Method for Quasi-linear PDEs).
  2. Put the curve in: c1​=φ(x0​(s),y0​(s),u0​(s)), c2​=ψ(x0​(s),y0​(s),u0​(s)).
  3. Eliminate s to get one relation H(c1​,c2​)=0.
  4. Replace c1​=φ(x,y,u), c2​=ψ(x,y,u): H(φ,ψ)=0 is the integral surface; solve for u if possible.

(Equivalent view: the surface is the union of the characteristics through the points of Γ.)

Example. ux​+2xuy​=y, u(0,y)=y2. Integrals: y−x2=c1​ and u−c1​x−3x3​=c2​. On x=0: c1​=s, c2​=s2, so c2​=c12​:

u=(y−x2)2+x(y−x2)+3x3​=(y−x2)2+xy−32​x3.

Example (quasi-linear, nonlinear solution). uux​+uy​=0, u(x,0)=x: integrals u=c1​, x−uy=c2​; data give c2​=c1​, so x−uy=u and u=1+yx​ (the inviscid Burgers equation with a linear profile).

When the Cauchy problem is solvable

The characteristic base curves must cross the projection of Γ transversally:

ay˙​0​−bx˙0​=0along Γ.

  • If Γ is nowhere characteristic: exactly one solution (locally).
  • If Γ is a characteristic and u0​ is compatible with the characteristic ODE: infinitely many solutions (any surface through the characteristic).
  • If Γ is a characteristic and the data are not compatible: no solution.

Worked pair. ux​+uy​=1: characteristics have direction (1,1,1). Data u=x on y=x is the curve (s,s,s), itself a characteristic: every u=x+g(x−y) with g(0)=0 works. Data u=0 on y=x would need u to grow like x along the characteristic: impossible. Geometrically the two data curves lie along the tangent direction, so they cannot determine a transverse surface.

Example (surfaces of revolution). yux​−xuy​=0 has u=f(x2+y2), whose characteristics are circles x2+y2= const at constant u. Data on a circle (e.g. u=1 on x2+y2=4) is a characteristic: not unique (u=1, u=4x2+y2​, … all work). Data on the line x=0, u=y2 crosses every circle (twice, symmetric: needs u0​ even): unique, u=x2+y2.

Traps
  • Forgetting that the data curve may meet one characteristic twice (the circle example): the data must agree at both points, otherwise there is no solution.
  • The solution may exist only locally: for ux​+uy​=u2, u(x,0)=cosx gives u=1−ycos(x−y)cos(x−y)​, which blows up where ycos(x−y)=1.

Intersection of integral surfaces

If two integral surfaces meet transversally along a curve C, then C is a characteristic: both tangent planes contain (a,b,c), and two distinct planes meet in exactly that line. So two different solutions can only branch apart along characteristics.

Cross-domain links

  • Classification of Second Order PDEs — the same idea reappears: characteristics are the curves along which second derivatives can jump.
