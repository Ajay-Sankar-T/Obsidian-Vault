Nodal and Mesh Analysis (AC)

EE1100AC-circuitsnodal-analysismesh-analysis
How to attack a problem
  1. Say what is asked and what is given.
  2. Pick the principle before calculating (open the hint).
  3. Solve symbolically, then plug in numbers.
  4. Check units and a limiting case.
  5. Be honest: mark it solved only if you could redo it.

← up: Tutorial 3 · builds on: Week 2, Week 7, Impedance and Series-Parallel AC Circuits

Both methods are structurally identical to their DC versions in Nodal and Mesh Analysis — replace R→Z and 1/R→Y=1/Z throughout, and solve the resulting linear system with complex arithmetic.

Nodal analysis (Q9 pattern)

Branch current between nodes a and b through impedance Z:

Iab​=ZVa​−Vb​​=Y(Va​−Vb​)

KCL at every non-reference node: ∑Ileaving​=0 (equivalently, leaving = entering).

One-node shortcut

If a single unknown node voltage V connects to three known potentials V1​,V2​,V3​ through Z1​,Z2​,Z3​:

Z1​V−V1​​+Z2​V−V2​​+Z3​V−V3​​=0⟹V=Y1​+Y2​+Y3​Y1​V1​+Y2​V2​+Y3​V3​​

— a weighted average by admittance, the AC analogue of the DC current-divider-style node formula; extremely fast for single-unknown-node problems.

Mesh analysis (Q11 pattern)

Write KVL around every independent mesh:

∑ZI=∑V

For two meshes sharing a common impedance Zc​:

(Z1​+Zc​)I1​−Zc​I2​=V1​,−Zc​I1​+(Z2​+Zc​)I2​=V2​

Memory: diagonal = sum of impedances around that mesh; off-diagonal = negative of the shared impedance — exactly the DC mesh-matrix pattern, just with complex entries.

Current through a shared branch

If mesh currents I1​,I2​ both traverse a common element but in opposite assumed directions:

Ibranch​=I1​−I2​

This is why Q11-style problems require subtracting the two mesh-current solutions to get the physical current through the shared impedance — a step easy to skip if you stop at "solve for I1​,I2​" without asking what physical branch current was actually requested.

Choosing nodal vs mesh

Same rule of thumb as DC (Week 2): fewer nodes → nodal is faster; fewer meshes → mesh is faster; a circuit with a load fed through a complicated sub-network is often faster via Thevenin reduction instead of writing out full nodal/mesh equations for the whole thing.
