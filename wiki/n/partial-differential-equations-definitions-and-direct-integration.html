Partial Differential Equations – Definitions and Direct Integration

What it is

A partial differential equation relates an unknown u(x,y,…) of several variables to its partial derivatives. We write p=ux​, q=uy​. The order is the highest derivative present.

Order Example What it models
1 ut​+cux​=0 transport at speed c
2 ut​=kuxx​ heat conduction
2 utt​=c2uxx​ vibrating string
2 uxx​+uyy​=0 steady heat, potential
3 ut​+uux​+uxxx​=0 shallow-water (KdV) waves

Classes of first-order PDE F(x,y,u,p,q)=0

Class Form Test
linear a(x,y)p+b(x,y)q+c(x,y)u=d(x,y) u,p,q appear to the first power, no products
semilinear a(x,y)p+b(x,y)q=c(x,y,u) coefficients of p,q depend on x,y only
quasi-linear a(x,y,u)p+b(x,y,u)q=c(x,y,u) linear in p,q
nonlinear anything else, e.g. p2+q2=1, pq=u

linear ⊂ semilinear ⊂ quasi-linear. A linear PDE with d≡0 is homogeneous; its solutions can be added. Identify the class before choosing a method: quasi-linear equations (all of the next four notes) yield to Lagrange's Method for Quasi-linear PDEs.

Classify: xp+yq=u linear homogeneous · p+(x+y)q=5u+ex linear non-homogeneous · p+q=u2 semilinear · up+q=0 quasi-linear · p2+q2=u2 nonlinear.

A PDE has a whole family of solutions

u=x2+y2 satisfies yux​−xuy​=0, and so do sin(x2+y2), ex2+y2 and in fact f(x2+y2) for any differentiable f. Constants of an ODE become arbitrary functions, and a general solution of an n-th order PDE typically contains n of them. Initial or boundary data pick out one member.

Solving by direct integration

Integrating with respect to one variable treats the others as constants, so the "constant" of integration is an arbitrary function of the remaining variables.

PDE Solution
ux​=x+y u=2x2​+xy+f(y)
uxy​=0 u=h(x)+g(y)
uxx​=y2cos2x, u(0,y)=u(π/2,y)=0 u=4y2​(1−cos2x−π4x​)
ux​=u u=f(y)ex
uxy​=ux​ (put v=ux​: vy​=v) u=eyF(x)+G(y)

Worked example (uxx​=y2cos2x with the two boundary conditions): integrating twice gives u=−4y2​cos2x+xf(y)+g(y). u(0,y)=0⇒g=4y2​; u(π/2,y)=0⇒4y2​+2π​f+4y2​=0⇒f=−πy2​. Check: uxx​=y2cos2x ✓, both boundary values vanish ✓.

Trap

Direct integration only works when the PDE can be integrated in one variable (a pure derivative in x or y, or after a substitution like v=ux​). For ap+bq=c with both derivatives present use characteristics.
