EE1100 Tutorial 4 — Q4 & Q5: RC Filter Design

How to attack a problem
  1. Say what is asked and what is given.
  2. Pick the principle before calculating (open the hint).
  3. Solve symbolically, then plug in numbers.
  4. Check units and a limiting case.
  5. Be honest: mark it “I got it” only if you could redo it.

Q4: Low Pass Filter Design

Problem: Remove noise from low-frequency signal. fc​=1kHz, C=1.6μF. Select R.

Theory

For a Low Pass Filter (LPF):

fc​=2πRC1​​

Solution

R=2πfc​C1​=2π×1000×1.6×10−61​

R=0.0100531​≈99.47Ω≈100Ω​

Q5: High Pass Filter Design

Problem: Lower cut-off frequency fc​=20kHz, R=1kΩ. Select C.

Theory

For a High Pass Filter (HPF):

fc​=2πRC1​​

Solution

C=2πfc​R1​=2π×20,000×10001​

C=1.2566×1081​≈7.957×10−9F=7.95nF​
