How to solve

“I see this kind of problem — what do I use?” Type a keyword or filter by course; open a card for the method.

First-order ODE: is it exact?Differential Equations
Use Test My​=Nx​. If yes, find the potential F with Fx​=M,Fy​=N. If not, look for an integrating factor (Integrating Factors, Exact Differential Equations).Open note →
First-order linear y′+P(x)y=Q(x)Differential Equations
Use Multiply by e∫Pdx and integrate: Linear Differential Equations.Open note →
Bernoulli y′+Py=QynDifferential Equations
Use Substitute v=y1−n to make it linear: Bernoulli Differential Equations.Open note →
Second order, constant coefficients, homogeneousDifferential Equations
Use Solve the characteristic equation; real, repeated or complex roots give the three forms: 2nd Order Linear ODE with Constant Coefficients.Open note →
Non-homogeneous, forcing is a polynomial, exponential or sinusoidDifferential Equations
Use Method of Undetermined Coefficients; multiply the trial by xs when it duplicates a homogeneous solution.Open note →
Non-homogeneous, any forcingDifferential Equations
Use Variation of Parameters: needs two independent solutions and their Wronskian.Open note →
One solution known, find anotherDifferential Equations
Use Reduction of Order (y2​=vy1​), or Abel's Formula for the Wronskian.Open note →
Are two solutions independent?Differential Equations
Use Compute the Wronskian: nonzero means independent (Linear Independence and the Wronskian).Open note →
Cauchy–Euler x2y′′+axy′+by=0Differential Equations
Use Try y=xm, or substitute x=et to get constant coefficients: Cauchy-Euler Equations.Open note →
Series solution at an ordinary pointDifferential Equations
Use Power-series method; the radius of convergence is the distance to the nearest singular point: Power Series Method, Radius of Convergence of Series Solutions.Open note →
Regular singular pointDifferential Equations
Use Frobenius method: solve the indicial equation, then use the case (distinct, equal, integer-separated roots): Frobenius Method - Indicial Equation and Three Cases.Open note →

Use Match y′′+x1−2a​y′+… to the template y=xau(bxc): Reducing Equations to Bessel Form.Open note →

Use Integrate by parts using (xνJν​)′=xνJν−1​ and (x−νJν​)′=−x−νJν+1​: Bessel Function Properties and Recurrence Relations.Open note →

Use Coefficient an​=∫rfyn​/∫ryn2​ with the right weight: Legendre Series and Fourier-Legendre Expansions, Fourier-Bessel Series, Sturm-Liouville Problems.Open note →
Eigenvalues of y′′+λy=0 with boundary conditionsDifferential Equations
Use Try λ<0, λ=0, λ>0 separately and apply both conditions: Sturm-Liouville Problems.Open note →
